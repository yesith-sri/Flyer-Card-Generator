# Installation Guide

Detailed installation and configuration steps.

## Installation Steps

### 1. Environment Setup
Follow the [Setup Guide](./SETUP.md) first.

### 2. Install Dependencies
```bash
npm install
```

### 3. Build the Project
```bash
npm run build
```

### 4. Verify Installation
```bash
npm test
```

## Configuration
- Check [Config README](../config/README.md) for detailed configuration options
- Review [Port Access](../config/PORT_ACCESS.md) for network configuration

## Troubleshooting
If you encounter issues:
1. Check the [Setup Guide](./SETUP.md)
