# Setup Guide

Complete setup instructions for the project.

## Prerequisites
- Node.js 14+
- npm or yarn
- Git

## Steps

### 1. Clone the repository
```bash
git clone <your-repo-url>
cd project
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure environment
See [Port Access Configuration](../config/PORT_ACCESS.md) for network settings.
